# Images and files

How to upload a picture or a document, describe it, mark what must never be cropped out, and find and delete files.

## The media library

All the website's pictures and files are in one place: the **Media library** (in the menu, under **Content**). Anything you upload once can be used in several places without uploading it again.

- **Upload.** Click **Upload** and choose your files, or simply **drag** them into the window (**Drop files to upload them**). You can upload several at once. You'll see a confirmation such as **Uploaded 3 files**.
- **Search.** The **Search media…** field searches by name. Next to it you can choose a type (**All types**, **Images**, **PDF**) and a folder (**All files**, **No folder**).
- **Folders.** You can put a file in a folder, so that event photos and partner logos, for example, don't get mixed up. A file's details have a **Folder** field: type a new name and the folder is created.
- **Load more.** In a large library, only part of it loads at first; click to see more.

Click a picture and a details panel opens on the right: **Type**, **Size**, **Uploaded**, where the file is **Used in**, and tools further down. Changes save themselves (**Changes to “…” saved**).

## Image description

Fill in an **Image description** for every picture. It's one sentence about what's in the photo. It's used for three things:

- blind people have it read out to them by their computer,
- it shows when the picture doesn't load,
- it helps Google understand what the page is about.

A good description says what the picture **shows**, not what the file is called:

| Poor | Good |
|---|---|
| `IMG_4821.jpg` | A baker taking a tray of fresh rolls out of the oven |
| Photo | The team at the start of the Tábor triathlon |
| Picture | The shop entrance from the street, with a bench beside the door |

Purely decorative pictures (an ornamental strip, say) can go without a description. Pictures like that are marked **no description** in the list. For pictures that carry information, always write a description.

When you're working on text and insert a picture, the admin asks you directly: **Describe the picture. One sentence on what it shows. Screen readers read it to blind visitors, and Google uses it.** For example: *Runners at the start of the Tábor triathlon*. The **Skip** button lets you add the description later.

A website with several languages can have the description in several languages. Then fill in the description for each language on the picture.

## Focal point (cropping)

The website often crops a picture so it fits a square or a wide strip. The admin has no way of knowing where the important part of the photo is. You tell it:

1. Open the picture in the library.
2. Click the picture **where it must stay in view**: a face, a logo, a product. The admin says, for example, **Focal point at 40 % × 30 %.**
3. That's it. The change saves itself.

You clear it with the **Clear** button by the focal point.

> **Tip:** This is most useful for photos of people and for a page's main pictures. It really pays off where the website shows a picture in a different shape from the photo itself.

## A picture or file in your content

A picture field (such as the **Cover photo** on a news item) has three kinds of button:

- **Upload a file** or **Click to upload**: a new file from your computer,
- **Choose from library**: a file that's already in the library,
- **Replace** and **Remove**: for a file that's already chosen. **Remove** only takes it off this page; it doesn't delete it from the library.

A field for a file to download (a price list, rules, a menu) works the same way, except that instead of a preview it shows the name and size, plus an **Open** button. A file like that is usually a PDF.

## Galleries

A field with several photos (a gallery, an album) lets you:

- add several pictures at once,
- change the order (**Move earlier**, **Move later**, or by dragging),
- add a **Caption** to each picture, which shows on the website.

A caption (visible text under the photo) isn't the same thing as the image description in the library (for screen readers and Google). Both are worth having.

For a gallery, the admin shows the **number of files**.

## Which files, and how big

You can upload:

- pictures: **JPG, PNG, WebP, GIF, AVIF**,
- **PDF**,
- **MP4** and **WebM** video,
- **MP3** audio.

The admin refuses other types (Word, Excel, ZIP, SVG) with the message **This kind of file can’t be uploaded. Use a picture (JPG, PNG, WebP, GIF, AVIF), a PDF, MP4/WebM video or MP3.** Convert Word and Excel files to PDF.

There's a size limit. If a file is over it, you'll see **The file is too large (at most … MB).** The limit is usually 10 MB, but your website may have a different one. Photos from a phone are often large. Make them smaller before uploading (in the Photos app, for example, or by choosing a "smaller size" when you send them by email). For a website, a width of about 2000 pixels is plenty.

Other messages you might see when uploading:

- **The file is empty. Pick it again, or try another one.**: the file got damaged while it was being copied.
- **That was a lot at once. Wait a minute and try again.**: upload in smaller batches.
- **Upload failed**: try again, or try another file.

## Where a file is used, and how to delete it

In a file's details, the **Used in** section lists the pages and places where it's used. If there's nothing there, you'll see **Not used anywhere.**

You delete a file with the **Delete** button. The admin asks **Delete “…”?** and warns you that the file is **removed for good**. If the file is still used somewhere, the admin won't let you delete it: **Used in content: remove it there first.** Remove it from the places listed under **Used in**, then delete it.

> **Watch out:** A file you delete in the library is gone for good. If someone used it in an email, for example, or in a link somewhere outside the website, it will stop working there.

A file you add straight to a page or news item tidies itself away from storage once you remove it from there, as long as nothing else uses it. Files uploaded in the **Media library** stay until you delete them yourself.

Someone with the **Author** role can change and delete only the files they uploaded themselves.

## The "Copy link" button

A file's details have a **Copy link** button. It copies the file's web address, which you can paste into an email, for example, or anywhere else. You'll see **Link copied**.
