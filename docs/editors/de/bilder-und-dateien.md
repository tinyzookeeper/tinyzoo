# Bilder und Dateien

Wie Sie ein Bild oder Dokument hochladen und beschreiben, festlegen, was beim Zuschneiden nicht abgeschnitten werden darf, und wie Sie Dateien finden und löschen.

## Die Medienbibliothek

Alle Bilder und Dateien der Website liegen an einem Ort: in der **Medienbibliothek** (im Menü im Bereich **Inhalte**). Was Sie einmal hochgeladen haben, können Sie an mehreren Stellen verwenden, ohne es erneut hochzuladen.

- **Hochladen.** Klicken Sie auf **Hochladen** und wählen Sie die Dateien aus, oder **ziehen** Sie sie direkt ins Fenster (**Dateien zum Hochladen ablegen**). Sie können mehrere auf einmal hochladen. Bestätigt wird das etwa mit **3 Dateien hochgeladen**.
- **Suchen.** Das Feld **Medien suchen…** sucht nach dem Namen. Daneben wählen Sie den Typ (**Alle Dateitypen**, **Bilder**, **PDF**) und den Ordner (**Alle Dateien**, **Ohne Ordner**).
- **Ordner.** Sie können eine Datei einem Ordner zuordnen, damit sich zum Beispiel Fotos von Veranstaltungen und Logos von Partnern nicht vermischen. In den Details der Datei gibt es das Feld **Ordner**: Geben Sie einen neuen Namen ein, und der Ordner wird angelegt.
- **Weitere laden.** Bei einer großen Bibliothek wird nur ein Teil geladen, den Rest sehen Sie nach einem Klick.

Klicken Sie auf ein Bild, öffnet sich rechts ein Panel mit Details: **Typ**, **Größe**, **Hochgeladen**, wo die Datei **Verwendet in** ist, und darunter die Werkzeuge. Änderungen werden von selbst gespeichert (**Änderungen an „…“ gespeichert**).

## Die Bildbeschreibung

Füllen Sie bei jedem Bild die **Bildbeschreibung** aus. Das ist ein Satz darüber, was auf dem Foto zu sehen ist. Sie dient drei Zwecken:

- Blinde Menschen lassen sie sich vom Computer vorlesen,
- sie erscheint, wenn das Bild nicht lädt,
- sie hilft Google zu verstehen, worum es auf der Seite geht.

Eine gute Beschreibung sagt, was das Bild **zeigt**, nicht, wie die Datei heißt:

| Schlecht | Gut |
|---|---|
| `IMG_4821.jpg` | Ein Bäcker holt ein Blech mit frischen Brötchen aus dem Ofen |
| Foto | Das Team am Start des Stadttriathlons |
| Bild | Eingang des Ladens von der Straße aus, neben der Tür eine Bank |

Rein dekorative Bilder (etwa ein Zierstreifen) können Sie ohne Beschreibung lassen. Solche Bilder werden in der Liste mit **keine Beschreibung** gekennzeichnet. Bei Bildern mit einer Aussage schreiben Sie immer eine Beschreibung.

Wenn Sie beim Schreiben ein Bild in den Text einfügen, fragt die Verwaltung direkt: **Bild beschreiben. Ein Satz zum Bildinhalt. Bildschirmleseprogramme lesen ihn blinden Besuchern vor, und Google verwendet ihn.** Beispiel: *Läufer am Start des Triathlons in Tábor*. Mit der Schaltfläche **Überspringen** können Sie die Beschreibung später ergänzen.

Eine Website mit mehreren Sprachen kann die Beschreibung in mehreren Sprachen haben. Füllen Sie beim Bild dann die Beschreibung für jede Sprache aus.

## Der Fokuspunkt (Bildausschnitt)

Die Website schneidet ein Bild oft zu, damit es in ein Quadrat oder einen breiten Streifen passt. Die Verwaltung kann nicht erkennen, wo auf dem Foto das Wichtigste ist. Das sagen Sie ihr:

1. Öffnen Sie das Bild in der Bibliothek.
2. Klicken Sie im Bild **auf die Stelle, die sichtbar bleiben muss**: ein Gesicht, ein Logo, ein Produkt. Die Verwaltung schreibt dann etwa **Fokuspunkt bei 40 % × 30 %.**
3. Fertig. Die Änderung wird von selbst gespeichert.

Aufheben können Sie den Fokuspunkt mit der Schaltfläche **Zurücksetzen**.

> **Tipp:** Das lohnt sich vor allem bei Fotos von Menschen und bei den Hauptbildern einer Seite. Wertvoll ist es überall dort, wo die Website ein Bild in einem anderen Seitenverhältnis zeigt, als das Foto hat.

## Ein Bild oder eine Datei im Inhalt

Bei einem Bildfeld (etwa **Titelbild** bei einer Neuigkeit) haben Sie drei Schaltflächen:

- **Datei hochladen** oder **Zum Hochladen klicken**: eine neue Datei von Ihrem Computer,
- **Aus der Medienbibliothek wählen**: eine Datei, die schon in der Bibliothek ist,
- **Ersetzen** und **Entfernen**: für eine Datei, die schon ausgewählt ist. **Entfernen** nimmt sie nur von dieser Seite, aus der Bibliothek löscht es sie nicht.

Ein Feld für eine Datei zum Herunterladen (Preisliste, Regeln, Speisekarte) funktioniert genauso, nur zeigt es statt einer Vorschau den Namen und die Größe und die Schaltfläche **Öffnen**. Eine solche Datei ist meist ein PDF.

## Galerie

Ein Feld mit mehreren Fotos (Galerie, Album) kann:

- mehrere Bilder auf einmal hinzufügen,
- die Reihenfolge ändern (**Nach vorne verschieben**, **Nach hinten verschieben** oder durch Ziehen),
- zu jedem Bild eine **Bildunterschrift** hinzufügen, die auf der Website erscheint.

Die Bildunterschrift (sichtbarer Text unter dem Foto) ist etwas anderes als die Bildbeschreibung in der Bibliothek (für Vorleseprogramme und Google). Beides ist nützlich.

Bei einer Galerie zeigt die Verwaltung die **Anzahl der Dateien** an.

## Welche Dateien und wie groß

Hochladen können Sie:

- Bilder: **JPG, PNG, WebP, GIF, AVIF**,
- **PDF**,
- Videos als **MP4** und **WebM**,
- Audio als **MP3**.

Andere Typen (Word, Excel, ZIP, SVG) lehnt die Verwaltung mit dem Text **Dieser Dateityp kann nicht hochgeladen werden. Verwenden Sie ein Bild (JPG, PNG, WebP, GIF, AVIF), ein PDF, ein MP4-/WebM-Video oder eine MP3-Datei.** ab. Wandeln Sie Word- und Excel-Dateien in PDF um.

Die Größe ist begrenzt. Ist eine Datei zu groß, erscheint **Die Datei ist zu groß (höchstens … MB).** Meist liegt die Grenze bei 10 MB, die Website kann aber eine andere haben. Fotos vom Smartphone sind oft groß. Verkleinern Sie sie vor dem Hochladen (etwa in der Fotos-App, oder wählen Sie beim Versenden per E-Mail eine „kleinere Größe“). Für die Website reicht eine Breite von etwa 2000 Pixeln.

Weitere Meldungen beim Hochladen:

- **Die Datei ist leer. Wählen Sie sie erneut oder versuchen Sie eine andere.**: Die Datei wurde beim Kopieren beschädigt.
- **Das war zu viel auf einmal. Warten Sie eine Minute und versuchen Sie es erneut.**: Laden Sie in kleineren Portionen hoch.
- **Hochladen fehlgeschlagen**: Versuchen Sie es erneut, gegebenenfalls mit einer anderen Datei.

## Wo eine Datei verwendet wird und wie Sie sie löschen

In den Details einer Datei steht im Bereich **Verwendet in** eine Liste der Seiten und Stellen, an denen sie verwendet wird. Steht dort nichts, sehen Sie **Wird nirgends verwendet.**

Eine Datei löschen Sie mit der Schaltfläche **Löschen**. Die Verwaltung fragt **„…“ löschen?** und weist darauf hin, dass sie **endgültig gelöscht** wird. Wird die Datei noch irgendwo verwendet, lässt die Verwaltung das Löschen nicht zu: **Wird in Inhalten verwendet. Entfernen Sie die Datei zuerst dort.** Entfernen Sie sie an den Stellen aus dem Bereich **Verwendet in**, und löschen Sie sie dann.

> **Achtung:** Eine Datei, die Sie in der Bibliothek löschen, ist endgültig weg. Hat jemand sie zum Beispiel in einer E-Mail oder in einem Link außerhalb der Website verwendet, funktioniert sie dort nicht mehr.

Eine Datei, die Sie direkt in eine Seite oder Neuigkeit einfügen, wird nach dem Entfernen dort von selbst aus dem Speicher aufgeräumt, wenn nichts anderes sie verwendet. Dateien, die Sie in der **Medienbibliothek** hochgeladen haben, bleiben, bis Sie sie selbst löschen.

Wer die Rolle **Autor** hat, kann nur Dateien ändern und löschen, die er selbst hochgeladen hat.

## Die Schaltfläche „Link kopieren“

In den Details einer Datei gibt es **Link kopieren**. Damit kopieren Sie die Internetadresse der Datei, die Sie dann etwa in eine E-Mail oder anderswo einfügen können. Bestätigt wird das mit **Link kopiert**.
