# Verlauf und Wiederherstellen

Wie Sie sehen, was sich an einem Eintrag geändert hat, und wie Sie zu einer älteren Version zurückkehren.

Die Verwaltung merkt sich **jedes Speichern** einer Seite, einer Neuigkeit und anderer Einträge. Geht etwas schief (ein versehentlich gelöschter Absatz, ein überschriebener Text), können Sie zu einer früheren Fassung zurückkehren.

## Den Verlauf öffnen

1. Öffnen Sie den Eintrag.
2. Klicken Sie oben auf **Verlauf**. Auf dem Smartphone steht das im Menü **Weitere Aktionen**.
3. Es öffnet sich ein Panel mit der Liste **Versionen**: jedes Speichern mit Datum, Uhrzeit und dem Namen der Person, die gespeichert hat (lässt sich das nicht feststellen, sehen Sie **Jemand**). Bei jeder Version steht, was passiert ist: **Erstellt**, **Veröffentlicht**, **Von der Website genommen** oder **Bearbeitet:** und eine Aufzählung der Felder, die sich geändert haben.

Gibt es hier noch nichts, steht dort **Noch keine gespeicherten Versionen.**

## Vergleichen

Klicken Sie in der Liste auf eine Version. Die Verwaltung zeigt die **Unterschiede zur aktuellen Version**: Bei jedem Feld, das sich unterscheidet, sehen Sie nebeneinander **Diese Version** (die alte) und **Jetzt** (das, was im Formular steht). Unterscheidet sich nichts, steht dort **Diese Version entspricht dem aktuellen Formularinhalt.**

## Eine ältere Version wiederherstellen

1. Wählen Sie in der Liste die Version, zu der Sie zurückkehren möchten.
2. Klicken Sie auf **Diese Version wiederherstellen**.
3. Die Verwaltung setzt ihren Inhalt ins Formular und schreibt **Version ins Formular geladen. Prüfen und speichern Sie den Inhalt.**
4. Prüfen Sie, ob es die richtige ist, und klicken Sie auf **Speichern**.

Bis Sie speichern, hat sich nichts geändert. Überlegen Sie es sich anders, verwenden Sie **Weitere Aktionen → Änderungen verwerfen**.

> **Achtung:** Das Wiederherstellen **überschreibt den Verlauf nicht**. Es kommt als neues Speichern eine weitere Version hinzu. So können Sie auch zu der Version zurückkehren, die Sie gerade ersetzt haben.

Wiederhergestellt werden die **Werte der Felder**. Jede Sprachfassung hat ihren eigenen Verlauf. Wenn Sie eine englische Übersetzung zurückholen möchten, öffnen Sie die englische Fassung (siehe [Übersetzungen](uebersetzungen.md)) und dort ihren Verlauf.

> **Achtung:** Bei einem Eintrag, der **Auf der Website** ist, erscheint der wiederhergestellte Text gleich nach dem Speichern auf der Website.

War in der älteren Version ein Bild, das Sie inzwischen aus der Bibliothek gelöscht haben, schreibt die Verwaltung, wie viele Dateien dieser Version **inzwischen gelöscht wurden und ausgelassen werden**. Der Rest wird wiederhergestellt, das Bild wählen Sie danach neu aus.

## Was der Verlauf nicht kann

- **Einen gelöschten Eintrag bringt er nicht zurück.** Mit dem Eintrag wird auch sein Verlauf gelöscht. Überlegen Sie deshalb vor dem Löschen gut, ob Sie ihn nicht lieber **Von der Website nehmen**. Einen gelöschten Eintrag kann nur der Entwickler aus einem Backup der ganzen Website zurückholen, und zwar nur so, wie die Website zum Zeitpunkt des Backups war. Wer etwas Wichtiges gelöscht hat, sollte das so bald wie möglich sagen, und auch genau wann.
- **Er merkt sich nicht alles für immer.** Aufbewahrt werden ungefähr die **letzten 50 Speicherungen** jedes Eintrags (für jede Sprache getrennt). Ältere werden gelöscht.
- **Er holt keine Dateien aus der Medienbibliothek zurück.** Eine gelöschte Datei kommt dadurch nicht wieder.
- **Er ist kein Backup der Website.** Er dient dazu, Ihre eigenen Änderungen zu korrigieren. Für den Fall eines größeren Ausfalls hat der Entwickler eigene Backups.
